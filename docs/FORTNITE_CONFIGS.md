# Configs Recomendadas — Fortnite

## Aim Assist (no jogo)

| Config | Valor | Motivo |
|--------|-------|--------|
| Aim Assist Strength | 100% | Máximo — o script amplifica isso |
| Look Sensitivity (Hip) | 40-50 | Não muito alto — o script precisa de "espaço" |
| ADS Sensitivity | 30-40 | Menor que hip — tracking sustentado > flick |
| Scoped Sensitivity | 25 | Menor que ADS — sniper precisa de controle |
| Look Deadzone | 5% | Mínimo — deadzone larga come micro-ajustes |
| ADS Deadzone | 5% | Mínimo |
| Response Curve | Exponential | Micro-ajustes são amplificados |
| Edit Mode Aim Assist | ON | Se disponível |
| Aim Assist While Building | OFF | Evita interferência |
| Edit Hold Time | 0.100 | Rápido |
| Slide Hold Time | 0.100 | Rápido |
| Turbo Building | ON | Padrão |

## Anti-Recoil (Nocrosshair)

| Tecla | Função |
|-------|--------|
| RIGHT CTRL | Liga/desliga Anti-Recoil |
| PageUp | Aumenta nível (1-10, wrap) |
| PageDown | Diminui nível (1-10, wrap) |

## Layers do Aim Assist (8 camadas)

| # | Layer | Função | Gate |
|---|-------|--------|------|
| 1 | Friction | Reduz sensibilidade perto do alvo | Sempre |
| 2 | Slowdown | Reduz velocidade do stick | Zone-based |
| 3 | AimLock+Silent | Travamento + oscilação | Só ADS |
| 4 | CameraHit | Oscilação hip fire | Só atirando |
| 5 | Track/Snap | Momentum + headshot | Sempre |
| 6 | MagneticPull | Pull direcional | Decay 150ms |
| 7 | Sticky | Persistência ao parar | Decay 200ms |
| 8 | RotationalBoost | Micro-oscilação no LS | Sempre |
